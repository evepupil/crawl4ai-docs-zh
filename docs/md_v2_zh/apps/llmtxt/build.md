**AI 编程助手提示：创建交互式 LLM 上下文构建器页面**

**目标：**

你的任务是创建一个具有 JavaScript 功能的交互式 HTML 网页，允许用户选择并组合不同的 `crawl4ai` LLM 上下文文件，生成一个可下载的 Markdown (`.md`) 文件。该工具将使用户能够根据自己的特定需求为其 AI 助手定制上下文。

**核心功能：**

1.  **显示 `crawl4ai` 组件：** 页面将列出所有可用的 `crawl4ai` 文档组件。
2.  **选择上下文类型：** 对于每个组件，用户可以选择要包含的上下文类型：
    *   记忆 (API 事实)
    *   推理 (How-to/原因)
    *   示例 (代码片段)
    (对于每个初始选中的组件，默认应全部选中)。
3.  **特殊的“聚合”上下文：** 包含特殊的、预先组合的上下文选项：
    *   "Vibe Coding" (为通用 AI 提示精心策划的混合内容)
    *   "所有库上下文" (整个库的所有记忆、推理和示例的全面聚合)。
4.  **获取并拼接：** 当用户点击“下载组合上下文”按钮时：
    *   JavaScript 将从服务器（从预定义的文件夹，例如 `/llmtxt/`）获取所有选定的 Markdown 文件的内容。
    *   它会将这些文件的内容连接成一个字符串。
5.  **客户端下载：** 拼接后的内容将作为下载文件提供给用户（例如，`custom_crawl4ai_context.md`）。

**输入/假设：**

*   **上下文文件位置：** 所有单独的上下文 Markdown 文件都位于服务器上一个名为 `llmtxt/` 的公开可访问文件夹中。
*   **文件命名约定：** 文件遵循模式：`crawl4ai_{{component_name}}_[memory|reasoning|examples]_content.llm.md`。
    *   `{{component_name}}` 可以包含下划线（例如，`deep_crawling`, `config_objects`）。
    *   特殊上下文的名称将类似于 `crawl4ai_vibe_content.llm.md` 和 `crawl4ai_all_content.llm.md`。
*   **组件列表：** 将提供给你一个 `crawl4ai` 组件列表。对于此实现，请使用以下列表：
    *   `core`
    *   `config_objects`
    *   `deep_crawling`
    *   `deployment` (涵盖安装和 Docker 部署)
    *   `extraction` (涵盖结构化数据提取)
    *   `markdown` (涵盖 Markdown 生成算法)
    *   `pdf_processing`
    *   *(此列表中不包含单独的 "Vibe Coding" 或 "所有库上下文"，因为它们是特殊的顶级选项)*

**详细的 UI/UX 要求：**

1.  **主页面结构：**
    *   **页眉：** "Crawl4AI 交互式 LLM 上下文构建器"
    *   **介绍：** 简要说明该工具的用途（来自你帮助起草的 `USING_LLM_CONTEXTS.md` 内容："Supercharging Your AI Assistant..."）。
    *   **选择区域：**
        *   **特殊聚合上下文（单选按钮或醒目的复选框）：**
            *   [ ] "Vibe Coding 上下文" (`crawl4ai_vibe_content.llm.md`)
            *   [ ] "所有库上下文 (全面)" (`crawl4ai_all_content.llm.md`)
            *   *行为：* 选择其中之一可能会禁用单个组件选择（反之亦然）以避免冗余，或者只是将它们添加到列表中。请考虑用户体验。一个简单的方法是，如果选择了聚合上下文，则它是*唯一*下载的内容。
        *   **单个组件选择（表格或复选框列表）：**
            *   一个标题为“选择单个组件和上下文类型：”的部分
            *   对于提供的列表中的每个组件：
                *   一个用于组件本身的主复选框（例如，`[ ] 核心功能`）。默认选中。
                *   嵌套复选框（缩进或分组）用于上下文类型，仅在父组件被选中时启用：
                    *   `[x] 记忆 (API 事实)`
                    *   `[x] 推理 (How-to/原因)`
                    *   `[x] 示例 (代码片段)`
                    (如果父组件被选中，这三个子复选框默认应被选中)。
    *   **操作按钮：**
        *   一个按钮："生成并下载组合上下文"
    *   **状态/反馈区域：** (可选，但用户体验好)
        *   显示消息，如“正在获取文件...”、“正在组合上下文...”、“开始下载...”或错误消息。

**最终输出：**

*   一个单独的 HTML 文件（例如，`interactive_context_builder.html`）。
*   相关的 JavaScript 代码（可以内联在 `<script>` 标签中或在单独的 `.js` 文件中）。
*   相关的 CSS 代码（可以内联在 `<style>` 标签中或在单独的 `.css` 文件中）。

这个交互式工具将极大地提升 `crawl4ai` 开发人员利用你专门的 LLM 上下文的用户体验。请确保 JavaScript 代码健壮并提供良好的用户反馈。

这个提示应该为你的 AI 编程助手提供一套非常清晰的要求和指南，以构建交互式上下文构建器。请记得向其提供“输入/假设”部分中提到的组件列表。
