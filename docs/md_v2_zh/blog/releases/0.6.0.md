# Crawl4AI v0.6.0 版本发布说明

我们很高兴地宣布 **Crawl4AI v0.6.0** 的发布，这是我们迄今为止最大、功能最丰富的更新。此版本引入了重大的架构升级、全新的地理感知爬取功能、高效抓取能力，以及为可扩展部署提供的实时流支持。

---

## 亮点功能

### 1. **全球感知爬虫**
如同身处世界任何地方一样进行爬取。v0.6.0 版本中，每次爬取都可以模拟：
- 特定的 GPS 坐标
- 浏览器区域设置
- 时区

示例：
```python
CrawlerRunConfig(
    url="https://browserleaks.com/geo",
    locale="en-US",
    timezone_id="America/Los_Angeles",
    geolocation=GeolocationConfig(
        latitude=34.0522,
        longitude=-118.2437,
        accuracy=10.0
    )
)
```
非常适合访问特定区域内容或测试全球行为。

---

### 2. **原生表格提取**
直接将 HTML 表格提取为 Pandas DataFrame 或 CSV 等可用格式，无需解析麻烦。所有表格数据可在 `result.media["tables"]` 下获取。

示例：
```python
raw_df = pd.DataFrame(
    result.media["tables"][0]["rows"],
    columns=result.media["tables"][0]["headers"]
)
```
这使得它非常适合抓取金融数据、定价页面或任何表格化内容。

---

### 3. **浏览器池化与预热**
我们彻底改进了浏览器管理。现在，多个浏览器实例可以池化，并且页面可以预热以实现超快速启动：
- 减少冷启动延迟
- 降低内存峰值
- 增强并行爬取稳定性

这为新的 **Docker Playground** 体验提供了动力，并简化了高负载爬取。

---

### 4. **流量与快照捕获**
需要完全可见性？您现在可以捕获：
- 完整的网络流量日志
- 控制台输出
- MHTML 页面快照，用于爬取后审计和调试

无需再猜测爬取过程中发生了什么。

---

### 5. **MCP API 和流支持**
我们开放了 **MCP socket 和 SSE 端点**，允许：
- 实时流式传输爬取结果
- 与代理或前端的实时集成
- 用于交互式爬取的新 Playground UI

这是使 Crawl4AI 实现实时化的重要一步。

---

### 6. **压力测试框架**
想要测试高负载下的性能吗？v0.6.0 包含一个新的内存压力测试套件，支持 1000+ URL 的工作负载。非常适合：
- 负载测试
- 性能基准测试
- 验证内存效率

---

## 核心改进
- Robots.txt 合规性
- 代理轮换支持
- 改进的 URL 规范化和会话重用
- 跨爬虫钩子的共享数据
- 新的页面路由逻辑

---

## 破坏性变更与弃用内容
- 移除了旧的 `crawl4ai/browser/*` 模块。请相应更新导入。
- `AsyncPlaywrightCrawlerStrategy.get_page` 现在使用新的函数签名。
- 已弃用的 markdown 生成器别名现在指向 `DefaultMarkdownGenerator` 并带有警告。

---

## 其他更新
- 使用 FastAPI 验证器替换了自定义验证逻辑
- Docker 构建现在基于 Chromium 层
- 全仓库清理：约 36,000 行新增，约 5,000 行删除
