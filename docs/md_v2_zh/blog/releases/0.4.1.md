### 更完善的懒加载处理（包含图片）

爬虫经常遗漏懒加载内容（尤其是图片）的问题一直让我困扰。在这个版本中，我确保 Crawl4AI **会等待所有图片加载完成** 再继续执行。这非常实用，因为许多现代网站只在图片进入视口或执行某些 JavaScript 后才加载它们。

启用方法如下：

```python
await crawler.crawl(
    url="https://example.com",
    wait_for_images=True  # 添加此参数确保图片完全加载
)
```

该功能会：
1. 等待页面达到"网络空闲"状态
2. 确保页面上所有图片已完全加载

这一改动能处理您可能遇到的大多数懒加载情况。

### 纯文本模式（快速轻量级爬取）

有时您完全不需要下载图片或处理 JavaScript。例如，当您只需要提取文本数据时，可以启用**纯文本模式**来加速爬取。通过禁用图片、JavaScript和其他重型资源，该模式在大多数情况下能使爬取速度**提升3-4倍**。

启用方法：

```python
crawler = AsyncPlaywrightCrawlerStrategy(
    text_mode=True  # 设为True启用纯文本爬取
)
```

当`text_mode=True`时，爬虫会自动：
- 禁用GPU处理
- 阻止图片和JavaScript资源
- 将视口大小缩减为800x600（可通过`viewport_width`和`viewport_height`覆盖）

如果您需要爬取数千个只需文本内容的页面，这个模式将节省大量时间和资源。

### 动态调整视口

另一个实用功能是能够**动态调整视口大小**以匹配页面内容。这对处理响应式布局或确保页面所有部分正确加载特别有帮助。

工作原理：
1. 爬虫在页面加载后计算其宽度和高度
2. 调整视口以适应内容尺寸
3. （可选）使用Chrome DevTools协议(CDP)模拟缩小以使所有内容适应视口

启用方法：

```python
await crawler.crawl(
    url="https://example.com",
    adjust_viewport_to_content=True  # 动态调整视口
)
```

这种方法确保整个页面都加载到视口中，特别是对于基于可见性加载内容的布局。

### 模拟整页滚动

有些网站会在您向下滚动时动态加载数据。为处理这种情况，我添加了**整页扫描**支持。它会模拟滚动到页面底部，检查新内容并捕获全部数据。

示例：

```python
await crawler.crawl(
    url="https://example.com",
    scan_full_page=True,   # 启用滚动
    scroll_delay=0.2       # 每次滚动后等待200ms（可选）
)
```

执行过程：
1. 爬虫分步向下滚动，每次滚动后等待内容加载
2. 当没有新内容出现时停止（即动态元素停止加载）
3. 必要时在完成前滚动回顶部

如果您曾为无限滚动页面头疼过，这个功能将解决您的烦恼。

### 复用浏览器会话（节省设置时间）

默认情况下，每次爬取页面都会创建新的浏览器上下文（或标签页）。对于小规模爬取没问题，但处理大型数据集时，复用同一会话更高效。

我为此添加了`create_session`方法：

```python
session_id = await crawler.create_session()

# 同一会话用于多次爬取
await crawler.crawl(
    url="https://example.com/page1",
    session_id=session_id  # 复用会话
)
await crawler.crawl(
    url="https://example.com/page2",
    session_id=session_id
)
```

这避免了为每个页面创建新标签页，加速爬取并减少内存使用。
