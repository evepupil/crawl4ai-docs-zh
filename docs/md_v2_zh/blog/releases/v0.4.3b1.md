# Crawl4AI 0.4.3：性能大幅提升与LLM集成

我们很高兴地宣布Crawl4AI 0.4.3版本发布，本次更新聚焦三大领域：速度与效率、LLM集成和核心平台改进。该版本显著提升了爬取性能，同时新增了强大的LLM驱动功能。

## ⚡ 速度与效率提升

### 1. 内存自适应调度系统
全新调度系统提供智能资源管理和实时监控：

```python
from crawl4ai import AsyncWebCrawler, CrawlerRunConfig, DisplayMode
from crawl4ai.async_dispatcher import MemoryAdaptiveDispatcher, CrawlerMonitor

async def main():
    urls = ["https://example1.com", "https://example2.com"] * 50
    
    # 配置内存感知调度
    dispatcher = MemoryAdaptiveDispatcher(
        memory_threshold_percent=80.0,  # 内存达到80%时自动节流
        check_interval=0.5,             # 每0.5秒检查一次
        max_session_permit=20,          # 最大并发会话数
        monitor=CrawlerMonitor(         # 实时监控
            display_mode=DisplayMode.DETAILED
        )
    )
    
    async with AsyncWebCrawler() as crawler:
        results = await dispatcher.run_urls(
            urls=urls,
            crawler=crawler,
            config=CrawlerRunConfig()
        )
```

### 2. 流式处理支持
实时处理爬取结果而无需等待所有结果：

```python
config = CrawlerRunConfig(stream=True)

async with AsyncWebCrawler() as crawler:
    async for result in await crawler.arun_many(urls, config=config):
        print(f"Got result for {result.url}")
        # 立即处理每个结果
```

### 3. 基于LXML的解析
新增LXML解析策略，解析速度提升高达20倍：

```python
config = CrawlerRunConfig(
    scraping_strategy=LXMLWebScrapingStrategy(),
    cache_mode=CacheMode.ENABLED
)
```

## 🤖 LLM集成

### 1. LLM驱动的Markdown生成
使用LLM进行智能内容过滤和组织：

```python
config = CrawlerRunConfig(
    markdown_generator=DefaultMarkdownGenerator(
        content_filter=LLMContentFilter(
            provider="openai/gpt-4o",
            instruction="Extract technical documentation and code examples"
        )
    )
)
```

### 2. 自动模式生成
使用LLM即时生成提取模式，无需手动编写CSS/XPath：

```python
schema = JsonCssExtractionStrategy.generate_schema(
    html_content,
    schema_type="CSS",
    query="Extract product name, price, and description"
)
```

## 🔧 核心改进

### 1. 代理支持与轮换
集成代理支持，具备自动轮换和验证功能：

```python
config = CrawlerRunConfig(
    proxy_config={
        "server": "http://proxy:8080",
        "username": "user",
        "password": "pass"
    }
)
```

### 2. Robots.txt合规性
内置robots.txt支持，采用SQLite缓存：

```python
config = CrawlerRunConfig(check_robots_txt=True)
result = await crawler.arun(url, config=config)
if result.status_code == 403:
    print("Access blocked by robots.txt")
```

### 3. URL重定向追踪
追踪重定向后的最终URL：

```python
result = await crawler.arun(url)
print(f"Initial URL: {url}")
print(f"Final URL: {result.redirected_url}")
```
