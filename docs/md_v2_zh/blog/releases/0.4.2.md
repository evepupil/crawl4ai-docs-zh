### 🔧 **可配置的浏览器和爬虫行为**

您曾要求更好地控制浏览器和爬虫的配置方式，现在它来了。通过新的 `BrowserConfig` 和 `CrawlerRunConfig` 对象，您可以按自己的需求精确设置浏览器和爬取行为。不再需要向 `arun` 塞入大量参数——只需传入您的配置即可开始。

**示例：**
```python
from crawl4ai import BrowserConfig, CrawlerRunConfig, AsyncWebCrawler

browser_config = BrowserConfig(headless=True, viewport_width=1920, viewport_height=1080)
crawler_config = CrawlerRunConfig(cache_mode="BYPASS")

async with AsyncWebCrawler(config=browser_config) as crawler:
    result = await crawler.arun(url="https://example.com", config=crawler_config)
    print(result.markdown[:500])
```

这种设置对于可扩展性来说是一个改变游戏规则的功能，它保持您的代码整洁且灵活，以便我们在未来添加更多参数。

请记住：如果您喜欢旧的方式，您仍然可以像以前一样直接向 `arun` 传递参数，不用担心！

### 🔐 **简化的会话管理**

这里有一个重要的功能：您现在可以直接传递本地存储和 cookies。无论是通过编程方式设置值，还是导入保存的 JSON 状态，会话管理都变得前所未有的简单。这对于需要身份验证的爬取来说是必备功能——只需导出一次您的存储状态，即可在多次运行中轻松重复使用。

**示例：**
1. 打开浏览器，手动登录，然后导出存储状态。
2. 导入 JSON 文件以实现无缝的身份验证爬取：

```python
result = await crawler.arun(
    url="https://example.com/protected",
    storage_state="my_storage_state.json"
)
```
