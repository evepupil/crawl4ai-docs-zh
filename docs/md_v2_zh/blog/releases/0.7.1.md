# 🛠️ Crawl4AI v0.7.1：小幅清理更新

*2025年7月17日 • 阅读时间 2 分钟*

---

这是一个小型维护版本，移除了未使用的代码并改进了文档。

## 🎯 变更内容

- 从 `crawl4ai/browser_manager.py` 中**移除了未使用的 StealthConfig**
- **更新了文档**，提供了更好的示例和参数说明
- 修复了文档中的**虚拟滚动配置**示例

## 🧹 代码清理

移除了未使用的 `StealthConfig` 导入和配置，这些代码在代码库中并未被使用。项目通过 JavaScript 注入使用自己的自定义隐身实现。

```python
# Removed unused code:
from playwright_stealth import StealthConfig
stealth_config = StealthConfig(...)  # This was never used
```

## 📖 文档更新

- 修复了自适应爬取参数示例
- 更新了会话管理文档
- 更正了虚拟滚动配置示例

## 🚀 安装

```bash
pip install crawl4ai==0.7.1
```

无破坏性变更 - 可直接从 v0.7.0 版本升级。
