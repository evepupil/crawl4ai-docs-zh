# 版本 0.4.0 发布摘要（2024 年 12 月 1 日）

## 概述
0.4.0 版本在内容过滤、多线程环境处理、用户代理生成和测试覆盖率方面引入了重大改进。主要亮点包括引入了 PruningContentFilter，旨在自动识别和提取 HTML 文档中最有价值的部分，以及增强了 BM25ContentFilter 的多功能性和有效性。

## 主要特性和增强

### 1. PruningContentFilter
- 引入了一种新的无监督内容过滤策略，该策略基于文本和链接密度等指标对 HTML 文档中相关性较低的节点进行评分和修剪。
- 专注于保留内容中最有价值的部分，使其在从复杂网页中提取相关信息时非常有效。
- 提供了完整的文档，包括更新的 README 和扩展的用户指南。

### 2. 用户代理生成器
- 添加了一个用户代理生成器实用程序，解决了兼容性问题并支持可定制的用户代理字符串。
- 默认情况下，生成器会为每个请求随机化用户代理以增加多样性，但用户可以根据特定场景进行自定义。

### 3. 增强的线程安全性
- 通过为并行处理添加更好的线程锁，改进了对多线程环境的处理，确保在运行多个线程时的一致性和稳定性。

### 4. 扩展的内容过滤策略
- 用户现在可以同时使用用于无监督提取的 PruningContentFilter 和用于基于用户查询的监督过滤的 BM25ContentFilter。
- 增强了 BM25ContentFilter，提高了处理页面标题、元标签和描述的能力，从而可以更有效地对文本块进行分类和聚类。

### 5. 文档更新
- 更新了示例和教程，以推广 PruningContentFilter 与 BM25ContentFilter 的使用，并为每个用例选择合适的过滤器提供了清晰的指导。

### 6. 单元测试增强
- 为 PruningContentFilter 添加了单元测试，以确保准确性和可靠性。
- 增强了 BM25ContentFilter 的测试，覆盖了更多的边缘情况和性能指标，特别是针对格式错误的 HTML 输入。

本次发布通过引入 PruningContentFilter、改进的 BM25ContentFilter 监督过滤以及强大的多线程处理能力，显著增强了 Crawl4ai 的内容提取能力。此外，用户代理生成器提供了急需的多功能性，解决了许多用户面临的兼容性问题。

我们鼓励用户尝试新的内容过滤方法，以确定最适合其需求的方案。
