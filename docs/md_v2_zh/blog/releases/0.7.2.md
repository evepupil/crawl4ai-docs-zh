# 🚀 Crawl4AI v0.7.2: CI/CD 与依赖优化更新

*2025年7月25日 • 阅读时间3分钟*

---

本次更新引入了自动化的 CI/CD 流水线以实现无缝发布，并优化了依赖项，使包更轻量、更高效。

## 🎯 新功能

### 🔄 自动化发布流水线
- **GitHub Actions CI/CD**: 在推送标签时自动发布到 PyPI 和 Docker Hub
- **多平台 Docker 镜像**: 支持 AMD64 和 ARM64 架构
- **版本一致性检查**: 确保标签、包和 Docker 版本对齐
- **自动化发布说明**: 自动创建 GitHub 发布

### 📦 依赖优化
- **将 sentence-transformers 移至可选依赖项**: 显著减小默认安装大小
- **更轻量的 Docker 镜像**: 优化的 Dockerfile，以实现更快的构建和更小的镜像
- **更好的依赖管理**: 核心依赖项与可选依赖项清晰分离

## 🏗️ CI/CD 流水线

新的自动化发布流程确保了稳定可靠的发布：

```yaml
# 通过一个简单的标签触发发布
git tag v0.7.2
git push origin v0.7.2

# 自动执行：
# ✅ 验证版本一致性
# ✅ 构建并发布到 PyPI
# ✅ 构建多平台 Docker 镜像
# ✅ 使用正确的标签推送到 Docker Hub
# ✅ 创建 GitHub 发布
```

## 💾 更轻量的安装

默认安装现在显著减小：

```bash
# 核心安装（更小，更快）
pip install crawl4ai==0.7.2

# 包含 ML 功能（包含 sentence-transformers）
pip install crawl4ai[transformer]==0.7.2

# 完整安装
pip install crawl4ai[all]==0.7.2
```

## 🐳 Docker 改进

增强的 Docker 支持，提供多平台镜像：

```bash
# 拉取最新版本
docker pull unclecode/crawl4ai:0.7.2
docker pull unclecode/crawl4ai:latest

# 可用标签：
# - unclecode/crawl4ai:0.7.2 (特定版本)
# - unclecode/crawl4ai:0.7 (次要版本)
# - unclecode/crawl4ai:0 (主要版本)
# - unclecode/crawl4ai:latest
```

## 🔧 技术细节

### 依赖变更
- `sentence-transformers` 从必需依赖项移至可选依赖项
- 减少默认安装约 500MB
- 在不需要 transformer 功能时不影响功能

### CI/CD 配置
- 用于自动化发布的 GitHub Actions 工作流
- 发布前的版本验证
- 并行的 PyPI 和 Docker Hub 部署
- Docker 镜像的自动标记策略

## 🚀 安装

```bash
pip install crawl4ai==0.7.2
```

无破坏性变更 - 可直接从 v0.7.0 或 v0.7.1 升级。
