## URL 种子发现工作流与架构

URL 发现策略、过滤管道和智能爬取工作流的可视化表示。

### URL 种子发现与深度爬取策略对比

```mermaid
graph TB
    subgraph "深度爬取方法"
        A1[起始 URL] --> A2[加载页面]

        A4 -->|是| A5[将下一页加入队列]
        A5 --> A2
        A4 -->|否| A6[完成]
        
        A7[⏱️ 实时发现]
```

### URL 发现数据流

```mermaid
sequenceDiagram
    participant User
    participant Seeder as AsyncUrlSeeder
    participant SM as Sitemap
    participant CC as Common Crawl
    participant Filter as URL Filter
    participant Scorer as BM25 Scorer
    
    User->>Seeder: urls("example.com", config)
    
    par 并行数据源
        Seeder->>SM: 获取 sitemap.xml
        SM-->>Seeder: 500 个 URL
    and
        Seeder->>CC: 查询 Common Crawl
        CC-->>Seeder: 2000 个 URL
    end
    
    Seeder->>Seeder: 合并并去重
    Note over Seeder: 2200 个唯一 URL
    
    Seeder->>Filter: 应用模式过滤器
    Filter-->>Seeder: 800 个匹配的 URL
    
    alt extract_head=True
        loop 对每个 URL
            Seeder->>Seeder: 提取 <head> 元数据
        end
        Note over Seeder: 标题、描述、关键词
    end
    
    alt 提供了查询
        Seeder->>Scorer: 计算相关性分数
        Scorer-->>Seeder: 已评分的 URL
        Seeder->>Seeder: 按 score_threshold 过滤
        Note over Seeder: 200 个相关 URL
    end
    
    Seeder->>Seeder: 按相关性排序
    Seeder->>Seeder: 应用 max_urls 限制
    Seeder-->>User: 前 100 个 URL 准备就绪，可供爬取
```

### SeedingConfig 决策树

```mermaid
flowchart TD
    A[SeedingConfig 设置] --> B{数据源策略？}
    
    B -->|快速且官方| C[source="sitemap"]
    B -->|全面| D[source="cc"]  
    B -->|最大覆盖范围| E[source="sitemap+cc"]
    
    C --> F{需要过滤？}
    D --> F
    E --> F
    
    F -->|是| G[设置 URL 模式]
    F -->|否| H[pattern="*"]
    
    G --> I{模式示例}
    I --> I1[pattern="*/blog/*"]
    I --> I2[pattern="*/docs/api/*"]
    I --> I3[pattern="*.pdf"]
    I --> I4[pattern="*/product/*"]
    
    H --> J{需要元数据？}
    I1 --> J
    I2 --> J
    I3 --> J
    I4 --> J
    
    J -->|是| K[extract_head=True]
    J -->|否| L[extract_head=False]
    
    K --> M{需要验证？}
    L --> M
    
    M -->|是| N[live_check=True]
    M -->|否| O[live_check=False]
    
    N --> P{需要相关性评分？}
    O --> P
    
    P -->|是| Q[设置查询 + BM25]
    P -->|否| R[跳过评分]
    
    Q --> S[query="搜索词"]
    S --> T[scoring_method="bm25"]
    T --> U[score_threshold=0.3]
    
    R --> V[性能调优]
    U --> V
    
    V --> W[设置 max_urls]
    W --> X[设置并发数]
    X --> Y[设置 hits_per_sec]
    Y --> Z[配置完成]
    
    style A fill:#e3f2fd
    style Z fill:#c8e6c9
    style K fill:#fff3e0
    style N fill:#fff3e0
    style Q fill:#f3e5f5
```

### BM25 相关性评分管道

```mermaid
graph TB
    subgraph "文本语料库准备"
        A1[URL 集合] --> A2[提取元数据]
        A2 --> A3[标题 + 描述 + 关键词]
        A3 --> A4[标记化文本]
        A4 --> A5[移除停用词]
        A5 --> A6[创建文档语料库]
    end
    
    subgraph "BM25 算法"
        B1[查询词] --> B2[词频计算]
        A6 --> B2
        B2 --> B3[逆文档频率]
        B3 --> B4[BM25 分数计算]
        B4 --> B5[分数 = Σ(IDF × TF × K1+1)/(TF + K1×(1-b+b×|d|/avgdl))]
    end
    
    subgraph "评分结果"
        B5 --> C1[URL 相关性分数]
        C1 --> C2{分数 ≥ 阈值？}
        C2 -->|是| C3[包含在结果中]
        C2 -->|否| C4[过滤掉]
        C3 --> C5[按分数降序排序]
        C5 --> C6[返回顶部 URL]
    end
    
    subgraph "分数示例"
        D1["python async tutorial" → 0.85]
        D2["python documentation" → 0.72]
        D3["javascript guide" → 0.23]
        D4["contact us page" → 0.05]
    end
    
    style B5 fill:#e3f2fd
```

### 完整的发现到爬取管道

```mermaid
stateDiagram-v2
    [*] --> Discovery
    
    Discovery --> SourceSelection: 配置数据源
    SourceSelection --> Sitemap: source="sitemap"
    SourceSelection --> CommonCrawl: source="cc"
    SourceSelection --> Both: source="sitemap+cc"
    
    Sitemap --> URLCollection
    CommonCrawl --> URLCollection
    Both --> URLCollection
    
    URLCollection --> Filtering: 应用模式
    Filtering --> MetadataExtraction: extract_head=True
    Filtering --> LiveValidation: extract_head=False
    
    MetadataExtraction --> LiveValidation: live_check=True
    MetadataExtraction --> RelevanceScoring: live_check=False
    LiveValidation --> RelevanceScoring
    
    RelevanceScoring --> ResultRanking: 提供了查询
    RelevanceScoring --> ResultLimiting: 无查询
    
    ResultRanking --> ResultLimiting: 应用 score_threshold
    ResultLimiting --> URLSelection: 应用 max_urls
    
    URLSelection --> CrawlPreparation: URL 准备就绪
    CrawlPreparation --> CrawlExecution: AsyncWebCrawler
    
    CrawlExecution --> StreamProcessing: stream=True
    CrawlExecution --> BatchProcessing: stream=False
    
    StreamProcessing --> [*]
    BatchProcessing --> [*]
    
    note right of Discovery : 🔍 智能 URL 发现
    note right of URLCollection : 📚 合并与去重
    note right of RelevanceScoring : 🎯 BM25 算法
    note right of CrawlExecution : 🕷️ 高性能爬取
```
