### 配置文件管理工作流

```mermaid
sequenceDiagram
    participant 用户
    participant CLI
    participant 配置文件管理器
    participant 浏览器
    participant 文件系统
    
    用户->>CLI: crwl profiles
    CLI->>配置文件管理器: 初始化配置文件管理器
    配置文件管理器->>文件系统: 扫描现有配置文件
    文件系统-->>配置文件管理器: 配置文件列表
    配置文件管理器-->>CLI: 显示交互式菜单
    CLI-->>用户: 显示选项
    
    Note over 用户: 用户选择“创建新配置文件”
    
    用户->>CLI: 创建配置文件 "linkedin-auth"
    CLI->>配置文件管理器: create_profile("linkedin-auth")
    配置文件管理器->>文件系统: 创建配置文件目录
    配置文件管理器->>浏览器: 使用新的用户数据目录启动浏览器
    浏览器-->>用户: 打开浏览器窗口
    
    Note over 用户: 用户手动登录到 LinkedIn
    
    用户->>浏览器: 导航并进行身份验证
    浏览器->>文件系统: 保存 Cookies、会话数据
    用户->>CLI: 按 'q' 保存配置文件
    CLI->>配置文件管理器: finalize_profile()
    配置文件管理器->>文件系统: 锁定配置文件设置
    配置文件管理器-->>CLI: 配置文件已保存
    CLI-->>用户: 配置文件 "linkedin-auth" 已创建
    
    Note over 用户: 后续使用
    
    用户->>CLI: crwl https://linkedin.com/feed -p linkedin-auth
    CLI->>配置文件管理器: load_profile("linkedin-auth")
    配置文件管理器->>文件系统: 读取配置文件数据
    文件系统-->>配置文件管理器: 用户数据目录
    配置文件管理器-->>CLI: 配置文件配置
    CLI->>浏览器: 使用现有配置文件启动浏览器
    浏览器-->>CLI: 认证会话准备就绪
    CLI->>浏览器: 导航到目标 URL
    浏览器-->>CLI: 带有认证上下文的爬取结果
    CLI-->>用户: 认证后的内容
```

stateDiagram-v2

### CLI 使用模式与最佳实践

```mermaid
timeline
    title CLI 工作流演进
    
    section 设置阶段
        安装 : pip install crawl4ai
              : crawl4ai-setup
        基本测试   : crwl https://example.com
        配置设置 : crwl config set defaults
    
    section 配置文件创建
        站点分析    : 识别认证要求
        配置文件创建 : crwl profiles
        手动登录     : 在浏览器中认证
        配置文件保存 : 按 'q' 保存
    
    section 开发阶段
        测试爬取      : crwl URL -p profile -v
        配置调优    : 调整浏览器/爬虫设置
        输出测试   : 尝试不同的输出格式
        错误处理   : 调试认证问题
    
    section 生产阶段
        自动化爬取 : crwl URL -p profile -o json
        批量处理 : 使用相同配置文件处理多个 URL
        监控       : 检查配置文件有效性
        维护      : 根据需要更新配置文件
```
