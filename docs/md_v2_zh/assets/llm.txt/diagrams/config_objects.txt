## 配置对象与系统架构

Crawl4AI 配置系统的可视化表示、对象关系及数据流模式。

### 配置对象关系

```mermaid
classDiagram
    class BrowserConfig {
        +browser_type: str
        +headless: bool
        +viewport_width: int
        +viewport_height: int
        +proxy: str
        +user_agent: str
        +cookies: list
        +headers: dict
        +clone() BrowserConfig
        +to_dict() dict
    }
    
    class CrawlerRunConfig {
        +cache_mode: CacheMode
        +extraction_strategy: ExtractionStrategy
        +markdown_generator: MarkdownGenerator
        +js_code: list
        +wait_for: str
        +screenshot: bool
        +session_id: str
        +clone() CrawlerRunConfig
        +dump() dict
    }
    
    class LLMConfig {
        +provider: str
        +api_token: str
        +base_url: str
        +temperature: float
        +max_tokens: int
        +clone() LLMConfig
        +to_dict() dict
    }
    
    class CrawlResult {
        +url: str
        +success: bool
        +html: str
        +cleaned_html: str
        +markdown: MarkdownGenerationResult
        +extracted_content: str
        +media: dict
        +links: dict
        +screenshot: str
        +pdf: bytes
    }
    
    class AsyncWebCrawler {
        +config: BrowserConfig
        +arun() CrawlResult
    }
    
    AsyncWebCrawler --> BrowserConfig : 使用
    AsyncWebCrawler --> CrawlerRunConfig : 接受
    CrawlerRunConfig --> LLMConfig : 包含
    AsyncWebCrawler --> CrawlResult : 返回
    
    note for BrowserConfig "控制浏览器\n环境与行为"
    note for CrawlerRunConfig "控制单个\n爬取操作"
    note for LLMConfig "配置LLM\n提供商与参数"
    note for CrawlResult "包含所有爬取\n输出与元数据"
```

### 配置生命周期序列

```mermaid
sequenceDiagram
    participant User
    participant BrowserConfig as 浏览器配置
    participant CrawlerConfig as 爬虫配置
    participant LLMConfig as LLM配置
    participant Crawler as AsyncWebCrawler
    participant Browser as 浏览器实例
    participant Result as CrawlResult
    
    User->>BrowserConfig: 使用浏览器设置创建
    User->>CrawlerConfig: 使用爬取选项创建
    User->>LLMConfig: 使用LLM提供商创建
    
    User->>Crawler: 使用BrowserConfig初始化
    Crawler->>Browser: 使用配置启动浏览器
    Browser-->>Crawler: 浏览器就绪
    
    User->>Crawler: arun(url, CrawlerConfig)
    Crawler->>Crawler: 应用CrawlerConfig设置
    
    alt 需要LLM提取
        Crawler->>LLMConfig: 获取LLM设置
        LLMConfig-->>Crawler: 提供商配置
    end
    
    Crawler->>Browser: 使用设置导航
    Browser->>Browser: 应用页面交互
    Browser->>Browser: 执行JavaScript（如指定）
    Browser->>Browser: 等待条件
    
    Browser-->>Crawler: 页面内容就绪
    Crawler->>Crawler: 按配置处理内容
    Crawler->>Result: 创建CrawlResult
    
    Result-->>User: 返回完整结果
    
    Note over User,Result: 配置对象控制每个环节
```
