### HTTP 请求生命周期序列

```mermaid
sequenceDiagram
    participant Client
    participant HTTPStrategy as HTTP 策略
    participant Session as HTTP 会话
    participant Server as 目标服务器
    participant Processor as 内容处理器
    
    Client->>HTTPStrategy: crawl(url, config)
    HTTPStrategy->>HTTPStrategy: validate_url()
    
    alt URL 类型检查
        HTTPStrategy->>HTTPStrategy: handle_file_url()
        Note over HTTPStrategy: file:// URLs
    else
        HTTPStrategy->>HTTPStrategy: handle_raw_content()
        Note over HTTPStrategy: raw:// 内容
    else
        HTTPStrategy->>Session: prepare_request()
        Session->>Session: apply_config()
        Session->>Session: set_headers()
        Session->>Session: setup_auth()
        
        Session->>Server: HTTP 请求
        Note over Session,Server: 带请求头的 GET/POST/PUT
        
        alt 成功响应
            Server-->>Session: HTTP 200 + 内容
            Session-->>HTTPStrategy: response_data
        else 重定向响应
            Server-->>Session: HTTP 3xx + Location
            Session->>Server: 跟随重定向
            Server-->>Session: HTTP 200 + 内容
            Session-->>HTTPStrategy: final_response
        else 错误响应
            Server-->>Session: HTTP 4xx/5xx
            Session-->>HTTPStrategy: error_response
        end
    end
    
    HTTPStrategy->>Processor: process_content()
    Processor->>Processor: clean_html()
    Processor->>Processor: extract_metadata()
    Processor->>Processor: generate_markdown()
    Processor-->>HTTPStrategy: processed_result
    
    HTTPStrategy-->>Client: CrawlResult
    
    Note over Client,Processor: 快速、轻量级处理
    Note over HTTPStrategy: 无浏览器开销
```

### HTTP 请求类型与配置

```mermaid
stateDiagram-v2
    [*] --> HTTPConfigSetup
    
    HTTPConfigSetup --> MethodSelection
    
    MethodSelection --> GET: 简单数据获取
    MethodSelection --> POST: 表单提交
    MethodSelection --> PUT: 数据上传
    MethodSelection --> DELETE: 资源删除
    
    GET --> HeaderSetup: 设置 Accept 请求头
    POST --> PayloadSetup: JSON 或表单数据
    PUT --> PayloadSetup: 文件或数据上传
    DELETE --> AuthSetup: 需要认证
    
    PayloadSetup --> JSONPayload: application/json
    PayloadSetup --> FormPayload: form-data
    PayloadSetup --> RawPayload: 自定义内容
    
    JSONPayload --> HeaderSetup
    FormPayload --> HeaderSetup
    RawPayload --> HeaderSetup
    
    HeaderSetup --> AuthSetup
    AuthSetup --> SSLSetup
    SSLSetup --> RedirectSetup
    RedirectSetup --> RequestExecution
    
    RequestExecution --> [*]: 请求完成
    
    note right of GET : 大多数爬取的默认方法
    note right of POST : API 交互，表单提交
    note right of JSONPayload : 结构化数据传输
    note right of HeaderSetup : User-Agent, Accept, 自定义请求头
```

### 批处理架构

```mermaid
sequenceDiagram
    participant Client
    participant BatchManager as 批处理管理器
    participant HTTPPool as 连接池
    participant Workers as HTTP 工作器
    participant Targets as 目标服务器
    
    Client->>BatchManager: batch_crawl(urls)
    BatchManager->>极好的Manager: create_semaphore(max_concurrent)
    
    loop 对于每个 URL 批次
        BatchManager->>HTTPPool: acquire_connection()
        HTTPPool->>Workers: assign_worker()
        
        par 并发处理
            Workers->>Targets: HTTP 请求 1
            Workers->>Targets: HTTP 请求 2
            Workers->>Targets: HTTP 请求 N
        end
        
        par 响应处理
            Targets-->>Workers: 响应 1
            Targets-->>Workers: 响应 2
            Targets-->>Workers: 响应 N
        end
        
        Workers->>HTTPPool: return_connection()
        HTTPPool->>BatchManager: batch_results()
    end
    
    BatchManager->>BatchManager: aggregate_results()
    BatchManager-->>Client: final_results()
    
    Note over Workers,Targets: 20-100 并发连接
    Note over BatchManager: 内存高效处理
    Note over HTTPPool: 连接复用优化
```
