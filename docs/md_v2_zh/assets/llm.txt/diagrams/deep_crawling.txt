## 深度爬取工作流与架构

多层级网站探索、过滤策略与智能爬取模式的可视化呈现。

### 深度爬取策略概览

```mermaid
flowchart TD
    A[开始深度爬取] --> B{策略选择}
    
    B -->|探索所有层级| C[BFS 广度优先策略]
    B -->|快速深入爬取| D[DFS 深度优先策略] 
    B -->|智能优先级| E[最佳优先策略]
    
    C --> C1[广度优先搜索]
    C1 --> C2[处理所有深度0链接]
    C2 --> C3[处理所有深度1链接]
    C3 --> C4[按深度层级继续]
    
    D --> D1[深度优先搜索]
    D1 --> D2[沿首个链接深入]
    D2 --> D3[达到最大深度后回溯]
    D3 --> D4[继续下一个分支]
    
    E --> E1[最佳优先搜索]
    E1 --> E2[为所有发现的URL评分]
    E2 --> E3[优先处理评分最高的URL]
    E3 --> E4[持续重新排序队列]
    
    C4 --> F[应用过滤器]
    D4 --> F
    E4 --> F
    
    F --> G{过滤链处理}
    G -->|域名过滤器| G1[检查允许/阻止的域名]
    G -->|URL模式过滤器| G2[匹配URL模式]
    G -->|内容类型过滤器| G3[验证内容类型]
    G -->|SEO过滤器| G4[评估SEO质量]
    G -->|内容相关性| G5[评分内容相关性]
    
    G1 --> H{通过所有过滤器？}
    G2 --> H
    G3 --> H
    G4 --> H
    G5 --> H
    
    H -->|是| I[添加到爬取队列]
    H -->|否| J[丢弃URL]
    
    I --> K{处理模式}
    K -->|流式处理| L[立即处理]
    K -->|批处理| M[收集所有结果]
    
    L --> N[将结果流式传输给用户]
    M --> O[返回完整结果集]
    
    J --> P{队列中还有更多URL？}
    N --> P
    O --> P
    
    P -->|是| Q{在限制范围内？}
    P -->|否| R[深度爬取完成]
    
    Q -->|最大深度OK| S{最大页面数OK}
    Q -->|超过最大深度| T[跳过更深层URL]
    
    S -->|低于限制| U[继续爬取]
    S -->|达到限制| R
    
    T --> P
    U --> F
    
    style A fill:#e1f5fe
    style R fill:#c8e6c9
    style C fill:#fff3e0
    style D fill:#f3e5f5
    style E fill:#e8f5e8
```

### 过滤链处理顺序

```mermaid
sequenceDiagram
    participant URL as 发现的URL
    participant Chain as 过滤链
    participant Domain as 域名过滤器
    participant Pattern as URL模式过滤器
    participant Content as 内容类型过滤器
    participant SEO as SEO过滤器
    participant Relevance as 内容相关性过滤器
    participant Queue as 爬取队列
    
    URL->>Chain: 处理URL
    Chain->>Domain: 检查域名规则
    
    alt 域名允许
        Domain-->>Chain: ✓ 通过
        Chain->>Pattern: 检查URL模式
        
        alt 模式匹配
            Pattern-->>Chain: ✓ 通过
            Chain->>Content: 检查内容类型
            
            alt 内容类型有效
                Content-->>Chain: ✓ 通过
                Chain->>SEO: 评估SEO质量
                
                alt SEO评分高于阈值
                    SEO-->>Chain: ✓ 通过
                    Chain->>Relevance: 评分内容相关性
                    
                    alt 相关性评分高
                        Relevance-->>Chain: ✓ 通过
                        Chain->>Queue: 添加到爬取队列
                        Queue-->>URL: 已加入爬取队列
                    else 相关性评分低
                        Relevance-->>Chain: ✗ 拒绝
                        Chain-->>URL: 已过滤 - 相关性低
                    end
                else SEO评分低
                    SEO-->>Chain: ✗ 拒绝
                    Chain-->>URL: 已过滤 - SEO质量差
                end
            else 无效内容类型
                Content-->>Chain: ✗ 拒绝
                Chain-->>URL: 已过滤 - 错误内容类型
            end
        else 模式不匹配
            Pattern-->>Chain: ✗ 拒绝
            Chain-->>URL: 已过滤 - 模式不匹配
        end
    else 域名被阻止
        Domain-->>Chain: ✗ 拒绝
        Chain-->>URL: 已过滤 - 阻止的域名
    end
```

### URL生命周期状态机

```mermaid
stateDiagram-v2
    [*] --> 已发现: 在页面上找到
    
    已发现 --> 过滤待处理: 进入过滤链
    
    过滤待处理 --> 域名检查: 应用域名过滤器
    域名检查 --> 模式检查: 域名允许
    域名检查 --> 已拒绝: 域名阻止
    
    模式检查 --> 内容检查: 模式匹配
    模式检查 --> 已拒绝: 模式不匹配
    
    内容检查 --> SEO检查: 内容类型有效
    内容检查 --> 已拒绝: 无效内容
    
    SEO检查 --> 相关性检查: SEO评分足够
    SEO检查 --> 已拒绝: SEO评分差
    
    相关性检查 --> 已评分: 计算相关性评分
    相关性检查 --> 已拒绝: 相关性低
    
    已评分 --> 已排队: 添加到优先级队列
    
    已排队 --> 爬取中: 被选中处理
    爬取中 --> 成功: 页面爬取成功
    爬取中 --> 失败: 爬取失败
    
    成功 --> 链接提取: 提取新链接
    链接提取 --> [*]: 处理完成
    
    失败 --> [*]: 记录失败
    已拒绝 --> [*]: 记录拒绝原因
    
    note right of 已评分 : 评分决定优先级<br/>在最佳优先策略中
    
    note right of 失败 : 错误记录包含<br/>深度和原因
```

### 错误处理与恢复流程

```mermaid
sequenceDiagram
    participant Strategy as 深度爬取策略
    participant Queue as 优先级队列
    participant Crawler as 页面爬取器
    participant Error as 错误处理器
    participant Result as 结果收集器
    
    Strategy->>Queue: 获取下一个URL
    Queue-->>Strategy: 返回最高优先级URL
    
    Strategy->>Crawler: 爬取页面
    
    alt 爬取成功
        Crawler-->>Strategy: 返回页面内容
        Strategy->>Result: 存储成功结果
        Strategy->>Strategy: 提取新链接
        Strategy->>Queue: 将新URL添加到队列
    else 网络错误
        Crawler-->>Error: 网络超时/失败
        Error->>Error: 记录错误详情
        Error->>Queue: 将URL标记为失败
        Error-->>Strategy: 跳过至下一个URL
    else 解析错误
        Crawler-->>Error: HTML解析失败
        Error->>Error: 记录解析错误
        Error->>Result: 存储失败结果
        Error-->>Strategy: 继续下一个URL
    else 速率限制触发
        Crawler-->>Error: 超出速率限制
        Error->>Error: 应用退避策略
        Error->>Queue: 重新排队URL并延迟
        Error-->>Strategy: 等待后重试
    else 深度限制
        Strategy->>Strategy: 检查深度约束
        Strategy-->>Queue: 跳过URL - 深度过大
    else 页面限制
        Strategy->>Strategy: 检查页面计数
        Strategy-->>Result: 停止爬取 - 达到限制
    end
    
    Strategy->>Queue: 请求下一个URL
    Queue-->>Strategy: 还有更多URL？
    
    alt 队列为空
        Queue-->>Result: 爬取完成
    else 队列有URL
        Queue-->>Strategy: 继续爬取
    end
```
