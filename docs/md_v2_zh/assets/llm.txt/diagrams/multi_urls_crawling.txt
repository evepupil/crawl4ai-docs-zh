## 多URL爬取工作流与架构

用于高效处理多个URL的并发爬取模式、资源管理和监控系统的可视化呈现。

### 多URL处理模式

```mermaid
flowchart TD
    A[多URL爬取请求] --> B{处理模式?}
    
    B -->|批量模式| C[收集所有URL]
    B -->|流式模式| D[逐个处理URL]
    
    C --> C1[所有URL入队]
    C1 --> C2[并发执行]
    C2 --> C3[等待全部完成]
    C3 --> C4[返回完整结果数组]
    
    D --> D1[URL入队]
    D1 --> D2[开始第一批]
    D2 --> D3[按可用性产出结果]
    D3 --> D4{更多URL?}
    D4 -->|是| D5[开始下一批URL]
    D4 -->|否| D6[流式完成]
    D5 --> D3
    
    C4 --> E[处理结果]
    D6 --> E
    
    E --> F[成功/失败分析]
    F --> G[结束]
    
    style C fill:#e3f2fd
    style D fill:#f3e5f5
    style C4 fill:#c8e6c9
    style D6 fill:#c8e6c9
```

### 内存自适应调度器流程

```mermaid
stateDiagram-v2
    [*] --> 初始化中
    
    初始化中 --> 监控内存: 启动调度器
    
    监控内存 --> 检查内存: 每个检查间隔
    检查内存 --> 内存正常: 内存 < 阈值
    检查内存 --> 内存过高: 内存 >= 阈值
    
    内存正常 --> 调度任务: 启动新爬取任务
    内存过高 --> 等待内存释放: 暂停调度
    
    调度任务 --> 任务运行中: 启动爬虫
    任务运行中 --> 任务完成: 爬取完成
    任务运行中 --> 任务失败: 爬取出错
    
    任务完成 --> 监控内存: 更新统计
    任务失败 --> 监控内存: 更新统计
    
    等待内存释放 --> 检查内存: 等待超时
    等待内存释放 --> 监控内存: 内存已释放
    
    note right of 内存过高: 防止内存溢出崩溃
    note right of 调度任务: 遵守最大会话许可
    note right of 等待内存释放: 可配置超时
```

### 速率限制与退避策略

```mermaid
sequenceDiagram
    participant C as 爬虫
    participant RL as 速率限制器
    participant S as 服务器
    participant D as 调度器
    
    C->>RL: 请求爬取URL
    RL->>RL: 计算延迟
    RL->>RL: 应用基础延迟(1-3秒)
    RL->>C: 应用延迟
    
    C->>S: HTTP请求
    
    alt 成功响应
        S-->>C: 200 OK + 内容
        C->>RL: 报告成功
        RL->>RL: 重置失败计数
        C->>D: 返回成功结果
    else 速率受限
        S-->>C: 429 请求过多
        C->>RL: 报告速率限制
        RL->>RL: 指数退避
        RL->>RL: 增加延迟(最大延迟上限)
        RL->>C: 应用更长延迟
        C->>S: 延迟后重试请求
    else 服务器错误
        S-->>C: 503 服务不可用
        C->>RL: 报告服务器错误
        RL->>RL: 适度退避
        RL->>C: 退避后重试
    else 超过最大重试次数
        RL->>C: 停止重试
        C->>D: 返回失败结果
    end
```

### 错误处理与恢复模式

```mermaid
stateDiagram-v2
    [*] --> 处理URL中
    
    处理URL中 --> 爬取尝试: 开始爬取
    
    爬取尝试 --> 成功: HTTP 200
    爬取尝试 --> 网络错误: 连接失败
    爬取尝试 --> 速率限制: HTTP 429
    爬取尝试 --> 服务器错误: HTTP 5xx
    爬取尝试 --> 超时: 请求超时
    
    成功 --> [*]: 返回结果
    
    网络错误 --> 重试检查: 检查重试次数
    速率限制 --> 退避等待: 应用指数退避
    服务器错误 --> 重试检查: 检查重试次数
    超时 --> 重试检查: 检查重试次数
    
    退避等待 --> 重试检查: 延迟后
    
    重试检查 --> 爬取尝试: 重试次数 < 最大重试
    重试检查 --> 失败: 重试次数 >= 最大重试
    
    失败 --> 错误日志: 记录失败详情
    错误日志 --> [*]: 返回失败结果
    
    note right of 退避等待: 对速率限制使用指数退避
    note right of 重试检查: 可配置最大重试次数
    note right of 错误日志: 详细错误跟踪
```
