## 深度爬取过滤器与评分器架构

智能深度爬取的高级URL过滤、评分策略与性能优化工作流程的可视化呈现。

### 过滤器链处理流程

```mermaid
flowchart TD
    A[URL输入] --> B{域名过滤器}

    C -->|✓ 通过| D{内容类型过滤器}
    C -->|✗ 失败| X2[拒绝：模式不匹配]
```

### 性能优化策略

```mermaid
sequenceDiagram
    participant Queue as URL队列
    participant Fast as 快速过滤器
    participant Slow as 慢速过滤器
    participant Score as 评分器
    participant Output as 已过滤URL
    
    Note over Queue, Output: 批处理（1000个URL）
    
    Queue->>Fast: 应用域名过滤器
    Fast-->>Queue: 60%通过（600个URL）
    
    Queue->>Fast: 应用模式过滤器
    Fast-->>Queue: 70%通过（420个URL）
    
    Queue->>Fast: 应用内容类型过滤器
    Fast-->>Queue: 90%通过（378个URL）
    
    Note over Fast: 快速过滤器淘汰62%的URL
    
    Queue->>Slow: 应用SEO过滤器（378个URL）
    Slow-->>Queue: 80%通过（302个URL）
    
    Queue->>Slow: 应用相关性过滤器
    Slow-->>Queue: 75%通过（227个URL）
    
    Note over Slow: 对剩余URL进行内容分析
    
    Queue->>Score: 计算综合评分
    Score-->>Queue: 评分与排序
    
    Queue->极>Output: 前100个评分最高的URL
    Output-->>Queue: 处理完成
    
    Note over Queue, Output: 总计：90%被过滤，保留10%高质量URL
```

### 自定义过滤器实现流程

```mermaid
stateDiagram-v2
    [*] --> 规划
    
    规划 --> 识别需求: 定义过滤标准
    识别需求 --> 选择类型: 二元与评分决策
    
    选择类型 --> 过滤器实现: 需要二元决策
    选择类型 --> 评分器实现: 需要质量评级
    
    过滤器实现 --> 继承URL过滤器: 扩展URLFilter基类
    评分器实现 --> 继承URL评分器: 扩展URLScorer基类
    
    继承URL过滤器 --> 实现应用: def apply(url) -> bool
    继承URL评分器 --> 实现评分: def _calculate_score(url) -> float
    
    实现应用 --> 添加逻辑: 添加自定义过滤逻辑
    实现评分 --> 添加逻辑
    
    添加逻辑 --> 测试过滤器: 单元测试
    测试过滤器 --> 优化性能: 性能优化
    
    优化性能 --> 集成: 与过滤器链集成
    集成 --> 生产: 部署到生产环境
    
    生产 --> 监控: 监控性能
    监控 --> 调优: 调整参数
    调优 --> 生产
    
    note right of 规划 : 考虑性能影响
    note right of 添加逻辑 : 处理边缘情况
    note right of 优化性能 : 缓存频繁访问的数据
```

### 评分算法工作流程

```mermaid
flowchart TD
    A[输入URL] --> B[解析URL组件]
    B --> C[提取特征]
    
    C --> D[域名分析]
    C --> E[路径分析] 
    C --> F[内容类型检测]
    C --> G[关键词提取]
    C --> H[新鲜度检测]
    
    D --> I[域名权威性评分]
    E --> J[路径深度评分]
    F --> K[内容类型评分]
    G --> L[关键词相关性评分]
    H --> M[新鲜度评分]
    
    I --> N[应用权重]
    J --> N
    K --> N
    L --> N
    M --> N
    
    N --> O[标准化评分]
    O --> P[计算最终评分]
    P --> Q{评分 >= 阈值？}
    
    Q -->|是| R[接受爬取]
    Q -->|否| S[拒绝URL]
    
    R --> T[添加到优先级队列]
    S --> U[记录拒绝原因]
    
    style A fill:#极浅蓝
    style P fill:#浅橙
    style R fill:#浅绿
    style S fill:#浅红
    style T fill:#浅绿
```
