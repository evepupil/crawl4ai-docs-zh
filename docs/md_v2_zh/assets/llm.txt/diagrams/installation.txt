### 基础安装时序图

```mermaid
sequenceDiagram
    participant 用户
    participant PyPI
    participant 系统
    participant Playwright
    participant 爬虫程序
    
    用户->>PyPI: pip install crawl4ai
    PyPI-->>用户: 下载完成
    
    用户->>系统: crawl4ai-setup
    系统->>Playwright: 安装浏览器二进制文件
    Playwright-->>系统: 安装Chromium/Firefox
    系统-->>用户: 配置完成
    
    用户->>系统: crawl4ai-doctor
    系统->>系统: 检查Python版本
    系统->>系统: 验证Playwright安装
    系统->>系统: 测试浏览器启动
    系统-->>用户: 诊断报告
    
    用户->>爬虫程序: 基础爬取测试
    爬虫程序->>Playwright: 启动浏览器
    Playwright-->>爬虫程序: 浏览器就绪
    爬虫程序->>爬虫程序: 访问测试URL
    爬虫程序-->>用户: 成功确认
```

### Docker多阶段构建流程

```mermaid
sequenceDiagram
    participant 开发者
    participant Git as GitHub仓库
    participant Docker as Docker引擎
    participant Registry as Docker Hub
    participant 用户
    
    开发者->>Git: 推送代码变更
    
    Docker->>Git: 克隆仓库
    Docker->>Docker: 阶段1 - 基础Python镜像
    Docker->>Docker: 阶段2 - 安装依赖
    Docker->>Docker: 阶段3 - 安装Playwright
    Docker->>Docker: 阶段4 - 拷贝应用代码
    Docker->>Docker: 阶段5 - 配置FastAPI服务器
    
    Note over Docker: 多架构构建
    Docker->>Docker: 构建linux/amd64
    Docker->>Docker: 构建linux/arm64
    
    Docker->>Registry: 推送多架构清单
    Registry-->>Docker: 构建完成
    
    用户->>Registry: docker pull unclecode/crawl4ai
    Registry-->>用户: 下载对应架构
    
    用户->>Docker: docker run配置
    Docker->>Docker: 启动容器
    Docker->>Docker: 初始化FastAPI服务器
    Docker->>Docker: 配置Playwright浏览器
    Docker-->>用户: 服务就绪于11235端口
```

    A[安装完成] --> B[运行crawl4ai-doctor]
    
    B --> C{Python版本检查}
    C -->|✓ 3.10+| D{Playwright检查}
    C -->|✗ < 3.10| C1[升级Python]
    C1 --> D
    
    D -->|✓ 已安装| E{浏览器二进制}
