### LLM提取策略工作流

```mermaid
sequenceDiagram
    participant 用户
    participant 爬虫
    participant LLM策略
    participant 分块器
    participant LLM提供商
    participant 解析器
    
    用户->>爬虫: 配置LLMExtractionStrategy
    用户->>爬虫: arun(网址, 配置)
    
    爬虫->>爬虫: 导航至URL
    爬虫->>爬虫: 提取内容(HTML/Markdown)
    爬虫->>LLM策略: 处理内容
    
    LLM策略->>LLM策略: 检查内容大小
    
    alt 内容 > 分块阈值
        LLM策略->>分块器: 分割为带重叠的块
        分块器-->>LLM策略: 返回块数组[]
        
        loop 对每个块循环
            LLM策略->>LLM提供商: 发送块 + 模式 + 指令
            LLM提供商-->>LLM策略: 返回结构化JSON
        end
        
        LLM策略->>LLM策略: 合并块结果
    else 内容 <= 阈值
        LLM策略->>LLM提供商: 发送完整内容 + 模式
        LLM提供商-->>LLM策略: 返回结构化JSON
    end
    
    LLM策略->>解析器: 验证JSON模式
    解析器-->>LLM策略: 验证后的数据
    
    LLM策略->>LLM策略: 跟踪令牌使用量
    LLM策略-->>爬虫: 返回extracted_content
    
    爬虫-->>用户: 包含JSON数据的CrawlResult
    
    用户->>LLM策略: show_usage()
    LLM策略-->>用户: 令牌计数和预估成本
```

### 自动模式生成流程

```mermaid
stateDiagram-v2
    [*] --> 检查缓存
    
    检查缓存 --> 缓存命中: 模式存在
    检查缓存 --> 采样页面: 模式缺失
    
    缓存命中 --> 加载模式
    加载模式 --> 快速提取
    
    采样页面 --> 提取HTML: 抓取采样URL
    提取HTML --> LLM分析: 发送HTML至LLM
    LLM分析 --> 生成模式: 创建CSS/XPath选择器
    生成模式 --> 验证模式: 测试生成模式
    
    验证模式 --> 模式有效: 有效选择器
    验证模式 --> 优化模式: 无效选择器
    
    优化模式 --> LLM分析: 带反馈迭代
    
    模式有效 --> 缓存模式: 保存以供复用
    缓存模式 --> 快速提取: 使用缓存模式
    
    快速提取 --> [*]: 无需再调用LLM
    
    note right of 检查缓存 : 一次性LLM成本
    note right of 快速提取 : 无限次快速复用
    note right of 缓存模式 : JSON文件存储
```

### 错误处理与回退策略

```mermaid
stateDiagram-v2
    [*] --> 主策略
    
    主策略 --> 成功: 提取成功
    主策略 --> 验证失败: 无效数据
    主策略 --> 提取失败: 无匹配项
    主策略 --> 超时错误: LLM超时
    
    验证失败 --> 回退策略: 尝试替代方案
    提取失败 --> 回退策略: 尝试替代方案
    超时错误 --> 回退策略: 尝试替代方案
    
    回退策略 --> 回退成功: 回退有效
    回退策略 --> 回退失败: 所有策略失败
    
    回退成功 --> 成功: 返回结果
    回退失败 --> 错误报告: 记录失败详情
    
    成功 --> [*]: 完成
    错误报告 --> [*]: 返回空结果
    
    note right of 主策略 : 优先尝试最快/最准确的方法
    note right of 回退策略 : 使用简单但可靠的方法
    note left of 错误报告 : 提供调试信息
```
