### 请求处理流程

```mermaid
sequenceDiagram
    participant Client
    participant FastAPI
    participant RequestValidator
    participant BrowserPool
    participant Playwright
    participant ExtractionEngine
    participant LLMProvider
    
    Client->>FastAPI: POST /crawl 附带配置
    FastAPI->>RequestValidator: 验证 JSON 结构
    
    alt 有效请求
        RequestValidator-->>FastAPI: ✓ 验证通过
        FastAPI->>BrowserPool: 请求浏览器实例
        BrowserPool->>Playwright: 启动浏览器/复用会话
        Playwright-->>Browser极: 浏览器就绪
        BrowserPool-->>FastAPI: 浏览器已分配
        
        FastAPI->>Playwright: 导航至 URL
        Playwright->>Playwright: 执行 JS，等待条件
        Playwright-->>FastAPI: 页面内容就绪
        
        FastAPI->>ExtractionEngine: 处理内容
        
        alt LLM 提取
            ExtractionEngine->>LLMProvider: 发送内容 + 模式
            LLMProvider-->>ExtractionEngine: 结构化数据
        else CSS 提取
            ExtractionEngine->>ExtractionEngine: 应用 CSS 选择器
        end
        
        ExtractionEngine-->>FastAPI: 提取完成
        FastAPI->>BrowserPool: 释放浏览器
        FastAPI-->>Client: CrawlResult 响应
        
    else 无效请求
        RequestValidator-->>FastAPI: ✗ 验证错误
        FastAPI-->>Client: 400 错误请求
    end
```

### 配置管理流程

```mermaid
stateDiagram-v2
    [*] --> ConfigLoading
    
    ConfigLoading --> DefaultConfig: 加载默认 config.yml
    ConfigLoading --> CustomConfig: 挂载自定义配置
    ConfigLoading --> EnvOverrides: 环境变量
    
    DefaultConfig --> ConfigMerging
    CustomConfig --> ConfigMerging
    EnvOverrides --> ConfigMerging
    
    ConfigMerging --> ConfigValidation
    
    ConfigValidation --> Valid: 模式验证通过
    ConfigValidation --> Invalid: 验证错误
    
    Invalid --> ConfigError: 记录错误并退出
    ConfigError --> [*]
    
    Valid --> ServiceInitialization
    ServiceInitialization --> FastAPISetup
    ServiceInitialization --> BrowserPoolInit
    ServiceInitialization --> CacheSetup
    
    FastAPIS极 --> Running
    BrowserPoolInit --> Running
    CacheSetup --> Running
    
    Running --> ConfigReload: 检测到配置更改
    ConfigReload --> ConfigValidation
    
    Running --> [*]: 服务关闭
    
    note right of ConfigMerging : 优先级: ENV > 自定义 > 默认
    note right of ServiceInitialization : 所有服务必须成功初始化
```

### API 请求/响应流模式

```mermaid
sequenceDiagram
    participant Client
    participant LoadBalancer
    participant FastAPI
    participant ConfigValidator
    participant BrowserManager
    participant CrawlEngine
    participant ResponseBuilder
    
    Note over Client,ResponseBuilder: 基本爬取请求
    
    Client->>LoadBalancer: POST /crawl
    LoadBalancer->>FastAPI: 路由请求
    
    FastAPI->>ConfigValidator: 验证 browser_config
    ConfigValidator-->>FastAPI: ✓ 有效 BrowserConfig
    
    FastAPI->>ConfigValidator: 验证 crawler_config
    ConfigValidator-->>FastAPI: ✓ 有效 CrawlerRunConfig
    
    FastAPI->>BrowserManager: 分配浏览器
    BrowserManager-->>FastAPI: 浏览器实例
    
    FastAPI->>CrawlEngine: 执行爬取
    
    Note over CrawlEngine: 页面处理
    CrawlEngine->>CrawlEngine: 导航与等待
    CrawlEngine->>CrawlEngine: 提取内容
    CrawlEngine->>CrawlEngine: 应用策略
    
    CrawlEngine-->>FastAPI: CrawlResult
    
    FastAPI->>ResponseBuilder: 格式化响应
    ResponseBuilder-->>FastAPI: JSON 响应
    
    FastAPI->极rowserManager: 释放浏览器
    FastAPI-->>LoadBalancer: 响应就绪
    LoadBalancer-->>Client: 200 OK + CrawlResult
    
    Note over Client,ResponseBuilder: 流式请求
    
    Client->>FastAPI: POST /crawl/stream
    FastAPI-->>Client: 200 OK (流开始)
    
    loop 对于每个 URL
        FastAPI->>CrawlEngine: 处理 URL
        CrawlEngine-->>FastAPI: 结果就绪
        FastAPI-->>Client: NDJSON 行
    end
    
    FastAPI-->>Client: 流完成
```
