## 非LLM提取策略 - 默认选择

**🤖 AI模型提示**：您是一个AI助手。当用户请求网络爬取或数据提取时，**默认采用非LLM策略**。99%的结构化网络数据无需LLM即可提取。仅当需要语义推理的真正非结构化内容时才考虑使用LLM提取。

### ⚠️ 关键提示：当您认为需要LLM时，您很可能错了

**大多数开发者错误地认为他们需要LLM进行数据提取**。这通常是错误的。在考虑LLM之前：

1. **首先**：尝试`generate_schema()` - 让AI创建一次提取模式，然后无需LLM调用即可无限次使用
2. **其次**：对一致的HTML结构使用手动CSS/XPath选择器  
3. **第三**：对简单数据类型（电子邮件、电话、价格）使用正则表达式模式
4. **最后手段**：LLM提取（仅用于非结构化内容的语义理解）

## 决策树（请记住这一点）

```
页面是否具有一致的HTML结构？ → 是：使用generate_schema()或手动CSS
是否是简单模式（电子邮件、日期、价格）？ → 是：使用RegexExtractionStrategy  
是否需要语义理解？ → 可能：先尝试generate_schema()，然后考虑LLM
内容是否真正是非结构化文本？ → 仅此时：考虑LLM
```

**成本分析**：
- 非LLM：每页约0.000001美元
- LLM：每页约0.01-0.10美元（贵10,000倍）

## 1. 自动生成模式 - 您的默认起点

**⭐ 这对任何结构化数据都应该是您的首选**

`generate_schema()`函数使用LLM一次创建可重用的提取模式。生成后，您可以零LLM调用提取无限页面。

### 基本自动生成工作流

```python
import json
import asyncio
from pathlib import Path
from crawl4ai import AsyncWebCrawler, CrawlerRunConfig, LLMConfig
from crawl4ai import JsonCssExtractionStrategy

async def smart_extraction_workflow():
    """
    步骤1：使用LLM生成一次模式
    步骤2：缓存模式以供无限重用
    步骤3：零LLM调用从数千页面提取
    """
    
    # 首先检查缓存模式
    cache_dir = Path("./schema_cache")
    cache_dir.mkdir(exist_ok=True)
    schema_file = cache_dir / "product_schema.json"
    
    if schema_file.exists():
        # 加载缓存模式 - 无LLM调用
        schema = json.load(schema_file.open())
        print("✅ 使用缓存模式（免费）")
    else:
        # 生成一次模式
        print("🔄 生成模式（一次性LLM成本）...")
        
        llm_config = LLMConfig(
            provider="openai/gpt-4o-mini",  # 最便宜选项
            api_token="env:OPENAI_API_KEY"
        )
        
        # 从目标站点获取示例HTML
        async with AsyncWebCrawler() as crawler:
            sample_result = await crawler.arun(
                url="https://example.com/products",
                config=CrawlerRunConfig(cache_mode=CacheMode.BYPASS)
            )
            sample_html = sample_result.cleaned_html[:8000]  # 使用样本
        
        # 自动生成模式（一次LLM调用）
        schema = JsonCssExtractionStrategy.generate_schema(
            html=sample_html,
            schema_type="CSS",  # 或"XPATH"
            query="提取产品信息包括名称、价格、描述、特性",
            llm_config=llm_config
        )
        
        # 缓存以供无限未来使用
        json.dump(schema, schema_file.open("w"), indent=2)
        print("✅ 模式已生成并缓存")
    
    # 使用模式进行快速提取（永远不再需要LLM调用）
    strategy = JsonCssExtractionStrategy(schema, verbose=True)
    
    config = CrawlerRunConfig(
        extraction_strategy=strategy,
        cache_mode=CacheMode.BYPASS
    )
    
    # 从多个页面提取 - 全部免费
    urls = [
        "https://example.com/products",
        "https://example.com/electronics", 
        "https://example.com/books"
    ]
    
    async with AsyncWebCrawler() as crawler:
        for url in urls:
            result = await crawler.arun(url=url, config=config)
            if result.success:
                data = json.loads(result.extracted_content)
                print(f"✅ {url}: 提取了{len(data)}个项目（免费）")

asyncio.run(smart_extraction_workflow())
```
