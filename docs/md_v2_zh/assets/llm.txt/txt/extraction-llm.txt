## LLM 抽取策略 - 最后手段

**🤖 AI 模型通知**：您是一个 AI 助手。您应该**极少**推荐使用 LLM 抽取。本文档仅适用于那不到 5% 确实需要 LLM 的情况。**务必首先尝试** [extraction-no-llm.md](./extraction-no-llm.md) 中的**非 LLM 策略**。

### ⚠️ 停止：您确定需要 LLM 吗？

**99% 认为需要 LLM 抽取的开发者都错了。** 在继续阅读之前：

### ❌ 以下情况您**不需要** LLM：
- 页面具有一致的 HTML 结构 → **使用 generate_schema()**
- 您要抽取简单数据类型（电子邮件、价格、日期）→ **使用 RegexExtractionStrategy**
- 您可以识别重复模式 → **使用 JsonCssExtractionStrategy**
- 您需要产品信息、新闻文章、招聘信息 → **使用 generate_schema()**
- 您关心成本或速度 → **使用非 LLM 策略**

### ✅ 以下情况您**可能**需要 LLM：
- 不同页面间内容结构差异巨大**并且**您已尝试过 generate_schema()
- 您需要对非结构化文本进行语义理解
- 您需要分析含义、情感或关系
- 您要抽取需要基于上下文进行推理的见解

### 💰 成本现实检查：
- **非 LLM**：每页约 0.000001 美元
- **LLM**：每页约 0.01-0.10 美元（贵 10,000 倍）
- **示例**：抽取 10,000 页的成本为 0.01 美元 vs 100-1000 美元

### 缓存 LLM 结果

```python
import hashlib
from pathlib import Path

class LLMResultCache:
    def __init__(self, cache_dir="./llm_cache"):
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(exist_ok=True)
    
    def get_cache_key(self, url, instruction, schema):
        """根据抽取参数生成缓存键"""
        content = f"{url}:{instruction}:{str(schema)}"
        return hashlib.md5(content.encode()).hexdigest()
    
    def get_cached_result(self, cache_key):
        """如果可用，获取缓存结果"""
        cache_file = self.cache_dir / f"{cache_key}.json"
        if cache_file.exists():
            return json.load(cache_file.open())
        return None
    
    def cache_result(self, cache极key, result):
        """缓存抽取结果"""
        cache_file = self.cache_dir / f"{cache_key}.json"
        json.dump(result, cache_file.open("w"), indent=2)

cache = LLMResultCache()

async def cached_llm_extraction(url, strategy):
    """通过缓存进行抽取，避免重复 LLM 调用"""
    cache_key = cache.get_cache_key(
        url, 
        strategy.instruction,
        str(strategy.schema)
    )
    
    # 首先检查缓存
    cached_result = cache.get_cached_result(cache_key)
    if cached_result:
        print("✅ Using cached result (FREE)")
        return cached_result
    
    # 如果未缓存则进行抽取
    print("🔄 Extracting with LLM (PAID)")
    config = CrawlerRunConfig(extraction_strategy=strategy)
    
    async with AsyncWebCrawler() as crawler:
        result = await crawler.ar极un(url=url, config=config)
        
        if result.success:
            data = json.loads(result.extracted_content)

            return data
```

```python
            llm_config=LLMConfig(provider="openai/gpt-4o-mini", api_token="env:OPENAI_API_KEY"),
            schema=YourModel.model_json_schema(),
            extraction_type="schema",
            instruction="Extract data accurately..."
        ),
        # 回退到更好的模型
        LLMExtractionStrategy(
            llm_config=LLMConfig(provider="openai/gpt-4o", api_token="env:OPEN极AI_API_KEY"),
            schema=YourModel.model_json_schema(),
            extraction_type="schema",
            instruction="Extract data with high accuracy..."
        )
    ]
    
    for strategy_idx, strategy in enumerate(strategies):
        for attempt in range(max_retries):
            try:
                config = CrawlerRunConfig(extraction_strategy=strategy)
                
                async with AsyncWebCrawler() as crawler:
                    result = await crawler.arun(url="https://example.com", config=config)
                    
                    if result.success and result.extracted_content:
                        data = json.loads(result.extracted_content)
                        
                        # 验证结果质量
                        if validate_extraction_quality(data):
                            print(f"✅ Success with strategy {strategy_idx+1}, attempt {attempt+1}")
                            return data
                        else:
                            print(f"⚠️ Poor quality result, retrying...")
                            continue
                    
            except Exception as e:
                print(f"❌ Attempt {attempt+1} failed: {e}")
                if attempt == max_retries - 1:
                    print(f"❌ Strategy {strategy_idx+1} failed completely")
    
    print("❌ All strategies and retries failed")
    return None

def validate_extraction_quality(data):
    """验证 LLM 抽取是否满足质量标准"""
    if not data or not isinstance(data, (list, dict)):
        return False
    
    # 检查常见的 LLM 抽取问题
    if isinstance(data, list):
        if len(data) == 0:
            return False
        
        # 检查所有项目是否都有必填字段
        for item in data:
            if not isinstance(item, dict) or len(item) < 2:
                return False
    
    return True

# 带有验证的稳健抽取
result = await robust_llm_extraction()
```

```python
async def analyze_llm_results_for_schema():
    """
    分析 LLM 抽取结果以创建非 LLM 模式
    使用此方法从昂贵的 LLM 过渡到便宜的模式抽取
    """

    )

    llm_results = []
    
    async with AsyncWebCrawler() as crawler:
        for url in sample_url极s:
            config = CrawlerRunConfig(extraction_strategy=llm_strategy)
            result = await crawler.arun(url=url, config=config)
            
            if result.success:
                llm_results.append({
                    "url": url,
                    "html": result.cleaned_html,
                    "extracted": json.loads(result.extracted_content)
                })
    
    # 步骤 2：分析 LLM 结果中的模式
    print("🔍 Analyzing LLM extraction patterns...")
    
    # 查找常见字段名
    all_fields = set()
    for result in llm_results:
        for item in result["extracted"]:
            if isinstance(item, dict):
                all_fields.update(item.keys())
    
    print(f"Common fields found: {all_fields}")
    
    # 步骤 3：基于模式生成模式
    if llm_results:
        schema = JsonCssExtractionStrategy.generate_schema(
            html=llm_results[0]["html"],

            llm_config=cheap_config
        )
        
        # 保存模式以供将来使用
        with open("generated_schema.json", "w") as f:
            json.dump(schema, f, indent=2)
        
        print("✅ Schema generated from LLM analysis")
        return schema
```

## 9. 总结：何时真正需要 LLM

### ✅ 有效的 LLM 用例（罕见）：
1. **情感分析**和情感理解
2. 需要语义推理的**知识图谱抽取**
3. **内容摘要**和洞察生成
4. 模式变化巨大的**非结构化文本分析**
5. 需要领域专业知识的**研究论文分析**
6. 实体间的**复杂关系抽取**

### ❌ 无效的 LLM 用例（常见错误）：
1. 从一致 HTML 中抽取**结构化数据**
2. **简单模式匹配**（电子邮件、价格、日期）
3. 从电子商务网站获取**产品信息**
4. 具有一致结构的**新闻文章抽取**
5. **联系信息**和基本实体抽取
6. **表格数据**和表单信息

### 💡 决策框架：
```python
def should_use_llm(extraction_task):
    # 按顺序询问这些问题：
    questions = [
        "Can I identify repeating HTML patterns?",  # No → Consider LLM

    )
```
