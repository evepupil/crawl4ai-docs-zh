# 自定义后端文档翻译指南

## 文件翻译范围

自定义后端文档系统通常由特定项目定制开发，使用动态渲染技术，主要翻译内容包括：

1. **内容文件**：
   - 数据库中存储的文档内容
   - Markdown、HTML或其他格式的内容文件
   - 内容管理系统(CMS)中的文本

2. **模板文件**：
   - 页面模板中的静态文本
   - 错误消息和提示
   - UI界面元素文本

3. **配置文件**：
   - 网站配置文件中的文本内容
   - 路由配置中的描述性文本
   - 国际化配置文件

4. **API响应**：
   - API返回的错误消息
   - 状态描述和帮助文本

5. **静态资源**：
   - 图片中的文本
   - JavaScript文件中的提示信息
   - CSS中的注释

## 部署步骤

### 准备工作

1. 获取源代码和数据库访问权限
```bash
git clone https://github.com/原始项目/文档系统.git
cd 文档系统
```

2. 安装依赖
```bash
# 根据项目技术栈安装相应依赖
npm install  # Node.js项目
pip install -r requirements.txt  # Python项目
composer install  # PHP项目
```

3. 配置开发环境
```bash
cp .env.example .env
# 编辑.env文件设置数据库连接等
```

### 翻译流程

#### 方法一：使用国际化框架

1. 识别项目使用的国际化框架（如i18n、gettext、Laravel Localization等）

2. 提取待翻译文本
```bash
# 示例：使用i18next提取文本
i18next-scanner --config i18next-scanner.config.js '**/*.{js,jsx,html}'

# 示例：使用Django提取文本
python manage.py makemessages -l zh_CN
```

3. 翻译提取的文本文件
   - 编辑语言文件（如`locales/zh/translation.json`或`.po`文件）
   - 或使用翻译管理工具（如POEditor、Crowdin等）

4. 更新配置以支持新语言
```javascript
// 示例：i18next配置
i18n.init({
  resources: {
    en: { translation: en_translations },
    zh: { translation: zh_translations }
  },
  lng: "zh",
  fallbackLng: "en"
});
```

#### 方法二：直接修改数据库内容

1. 创建数据库备份
```bash
# MySQL示例
mysqldump -u username -p database_name > backup.sql
```

2. 创建翻译版本的内容表或字段
   - 可能需要修改数据库结构以支持多语言
   - 或创建平行的翻译表

3. 导入翻译内容
   - 使用SQL脚本批量更新
   - 或通过管理界面手动添加翻译

### 构建与测试

1. 启动开发服务器
```bash
# 示例：Node.js应用
npm run dev

# 示例：Django应用
python manage.py runserver
```

2. 测试不同语言版本的显示效果
   - 切换语言设置
   - 检查所有页面的翻译完整性
   - 测试特殊字符和长文本的显示

### 部署方法

1. **更新数据库**：
   - 执行数据库迁移脚本
   - 导入翻译数据

2. **更新应用代码**：
   - 部署更新后的应用代码
   - 更新配置文件

3. **清除缓存**：
   - 清除服务器缓存
   - 重启应用服务

4. **CDN配置**：
   - 更新CDN缓存
   - 配置语言相关的路由规则

## 注意事项

1. **数据库结构设计**：
   - 了解系统如何存储多语言内容（单独字段、单独表或JSON结构）
   - 确保翻译不破坏数据库完整性

2. **动态内容处理**：
   - 注意处理动态生成的内容
   - 确保翻译系统能处理运行时生成的文本

3. **API响应翻译**：
   - 确保API响应的国际化处理
   - 测试不同语言环境下API的行为

4. **URL结构**：
   - 了解系统如何处理多语言URL（如`/zh/docs/`或`?lang=zh`）
   - 确保内部链接在语言切换后仍然有效

5. **搜索功能**：
   - 确保搜索引擎能正确索引翻译内容
   - 测试不同语言的搜索功能

6. **权限控制**：
   - 确保翻译内容遵循相同的权限控制
   - 测试不同用户角色对翻译内容的访问

7. **缓存策略**：
   - 了解系统的缓存机制
   - 确保翻译内容正确缓存和更新

## 自动化工具建议

1. 创建自动化脚本提取和更新翻译
2. 使用翻译管理系统（如Lokalise、Crowdin）
3. 设置翻译质量检查工具
4. 建立翻译更新的CI/CD流程

## 维护更新

1. 建立内容更新通知机制，及时获知原始内容的变化
2. 创建翻译差异比较工具，快速识别需要更新的内容
3. 定期审核翻译质量和完整性
4. 建立用户反馈渠道，收集翻译问题报告
