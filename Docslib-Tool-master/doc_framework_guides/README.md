# 开源文档翻译框架指南

本目录包含了针对不同类型文档框架的翻译指南，帮助您了解如何翻译和部署各种类型的开源项目文档。

## 文档框架类型

开源项目文档通常使用以下几种框架类型：

```
A[静态生成] --> B[纯静态]
A --> C[动态渲染]
A --> D[混合型]
B --> B1[MkDocs]
B --> B2[Docusaurus]
B --> B3[GitBook]
C --> C1[ReadTheDocs]
C --> C2[自定义后端]
D --> D1[部分静态+API]
```

## 如何使用这些指南

1. 首先确定您要翻译的开源项目使用的文档框架类型
2. 查阅相应的翻译指南，了解翻译范围和部署步骤
3. 按照指南中的步骤进行翻译和部署
4. 参考注意事项和自动化工具建议，提高翻译效率和质量

## 通用翻译建议

无论使用哪种框架，以下建议适用于所有开源文档翻译项目：

1. **保持一致性**：使用术语表确保专业术语翻译一致
2. **保留格式**：保持原始文档的格式和结构
3. **测试链接**：确保内部链接在翻译后仍然有效
4. **图片本地化**：如果图片包含文本，考虑创建本地化版本
5. **自动化工具**：使用翻译记忆工具和脚本提高效率
6. **定期同步**：与原始文档保持同步，及时更新翻译
